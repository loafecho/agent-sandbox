# coder: a long-lived interactive coding box

An OpenShell gateway on the agent host (VM 150 in the examples) and one long-lived microVM box named `coder`,
where Claude Code works. The box starts with **no network rules**: every outbound door is a named,
reviewed rule, and every credential is an OpenShell provider the box never sees in plain text.

House rule: every script is read-only or a dry run by default. Changes need `--yes-write`.
No script here reads, prints or stores a credential value. Credential and access-path steps are the operator's.

| File | Step | What it does |
|---|---|---|
| `bin/install-gateway.sh` | B1 | Copies `gateways/interactive/gateway-setup.sh` + config to the agent host and runs it as root: `openshell` user (kvm only, linger), OpenShell 0.1.1 `.deb` (sha256 checked, binaries compared with recorded hashes), gateway user service, CLI registration. `--remove --yes-write` is the rollback. |
| `bin/build-image.sh` | B2 | Builds `coder-box:<tag>`, checks no login or token is inside, exports a rootfs tar with a checksum. `--yes-write` copies it to the agent host. |
| `bin/create-box.sh` | B1, B2 | `--test` creates the throwaway box `boxtest` (one control door). Without it, the real box `coder` (no network rules). |
| `bin/box-deny-check.sh` | every rule change | The standing check. `--box` inside the box: every private target must be refused and an allowed host must answer. `--host` as `coder` on the VM: the control that proves the checker can see an open door. Baked into the image at `/opt/coder/`. |
| `bin/prove-gateway.sh` | B1 | Kernel differs from the host's, standing check with both controls, the `coder` host user can't touch the gateway. `--after-reboot`, `--cleanup`. |
| `bin/prove-box.sh` | B2 | `--size`, `--persist`, `--after-reboot`, `--loop-deny`, `--loop-open`, `--loop-closed` (the full request → pending rule → approve → close loop). |
| `bin/osh` | any | `openshell ...` on the agent host as the `openshell` user. |
| `bin/door.sh` | any | Open or close one named door from `openshell/doors.tsv`. Dry run validates the change on the gateway without applying it. |
| `bin/login`, `bin/connect` | B3 | The operator's terminal lines: open the two Anthropic doors and sign in inside the box; an interactive shell. |
| `image/` | B2 | Dockerfile, `boot.sh` (the box's main process: starts `~/.coder-box/services.sh`, flushes to disk every 5 s because a stop is a hard kill), `profile.sh`. |
| `openshell/policy.yaml` | any | **The record** of the live box's rules (file rules + every named door). Re-capture after an approved door with `bin/drift-check.sh --capture`, then commit. `_provider_*` blocks are left out; the gateway builds them from attached providers. |
| `openshell/providers.tsv` | B9 | Which providers exist, which secret feeds each, which box gets it. Names only, never values. |
| `openshell/profile-*.yaml` | B9 | Custom provider profiles: `cloudflare` (writes scoped to one Pages project) and `coder-switchboard` (generated by `switchboard/gen.py`). |
| `bin/set-provider.sh` | B9 | The operator's line. Secrets manager → gateway provider over ssh stdin, create or update; `--attach` attaches to the box. Re-run after rotating. |
| `bin/restart-rc.sh` | any | Shows the box's Remote Control loop; `--yes-write` restarts it fully detached (needed after a provider or `services.sh` change). |
| `bin/drift-check.sh` | any | Read-only. PASS/FAIL: live rules == `policy.yaml`, providers == `providers.tsv`, profiles imported, secret names present, zero pending rules. Exit 0 = clean. |
| `bin/placeholder-scan.py` | any | Finds text that would break a Claude chat in a box once a provider is attached (OpenShell refuses request bodies that carry its own placeholder syntax). Run on anything a box chat may read. |
| `systemd/coder-box.service` | B2 | Only if the box does not return by itself after a VM reboot. |

The scripts run from the admin workstation over one SSH key (`AGENT_HOST`, `AGENT_HOST_KEY` in `bin/lib.sh`).

## Adding a token to the box

1. The operator creates the token and stores it in the secrets manager (env `prod`). Nowhere else.
2. Add a row to `openshell/providers.tsv` (and a `profile-*.yaml` if no built-in profile fits; `openshell profile lint` first, then import).
3. The operator: `bin/set-provider.sh <name> --attach`. Then `bin/restart-rc.sh --yes-write`; open chats never get the new variable.
4. `bin/drift-check.sh` must print `DRIFT-CHECK: CLEAN`. Commit.

Rotating = update the value in the secrets manager, re-run step 3 without `--attach`.
